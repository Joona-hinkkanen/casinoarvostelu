# Casinoarvostelu

Yksinkertainen ja tumma frontend-pohja rahapelisivustojen arvostelusivustolle.

## Tiedostot

| Tiedosto     | Sisältö                        |
| ------------ | ------------------------------ |
| `index.html` | Sivun rakenne                  |
| `styles.css` | Ulkoasu ja värit               |
| `script.js`  | JavaScript (toistaiseksi vähän)|

## Muokkaaminen

- **Värit:** `styles.css` → `:root`-muuttujat.
- **Tekstit:** `index.html` (hero, navigaatio, footer).
- **Arvostelukortit:** lisää kortit `index.html`-tiedoston kohtaan
  `<div class="review-area" id="arvostelut-lista">`.
- **Haku:** `script.js` sisältää valmiin kohdan, johon hakulogiikan voi lisätä.

Ei kirjautumista, tietokantaa eikä ulkoisia riippuvuuksia.

## Paikallinen esikatselu

Avaa `index.html` selaimessa.
